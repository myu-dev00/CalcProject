# 💻 CalcProject :: Java를 활용한 계산기 프로그램

Java 콘솔 환경에서 동작하는 계산기 프로그램  
사용자에게서 두 정수를 입력 받아 사칙연산(+, -, *, /)을 수행하고, 연산 결과를 출력 함

---

## 📁 프로젝트 구조

```plaintext
v1/
└── Main.java // 프로그램 실행 및 전체 로직 포함
```

---

## 📌 주요 기능

- 예외 처리 `(아래 입력 유효성 검사 참고)`
- 소수점 자리수에 따른 출력 포맷 제어
- `"exit" or "EXIT"` 입력 전까지 반복 수행

## ⏬ 동작 흐름

1. 사용자로부터 두 정수를 입력 받음
2. 사칙연산 기호(`+`, `-`, `*`, `/`) 중 하나를 입력받음
3. 잘못된 연산자 또는 0으로 나누는 경우 경고 메시지를 출력 및 재연산
4. 소수점 자리 수에 따른 알맞은 결과 출력
5. `"exit" or "EXIT"` 입력 전까지 반복 수행

## 📜 결과값 출력 방식

- 결과가 정수형이면 소수점 없이 출력
- 소수점 이하 2자리 이하면 그대로 출력
- 소수점 이하 3자리 이상이면 소수점 셋째 자리까지 출력 (예: `%.3f`)
- 결과가 0.000이면 경고 메시지 포함 출력

## 📋 기능 예시
```plaintext
===========계산기=========== 첫 번째 숫자를 입력하세요: 10
두 번째 숫자를 입력하세요: 5
사칙연산 기호를 입력하세요(+, -, *, /): /
결과: 2

더 계산하시겠습니까? (exit 입력시 종료)
```

## ✅ 특이사항 및 예외 처리

- 정수가 0보다 작으면 재입력 요청
- 연산자가 (`+`, `-`, `*`, `/`) 아니면 다시 입력
- `/` 연산에서 0으로 나누는 경우 경고 메세지 출력 및 재연산
