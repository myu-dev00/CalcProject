# 💻 CalcProject :: Java를 활용한 계산기 프로그램

Java 콘솔 환경에서 동작하는 계산기 프로그램입니다.  
사용자에게서 두 정수를 입력 받아 사칙연산(+, -, *, /)을 수행하고, 연산 결과를 저장 및 관리할 수 있습니다.

---

## 📁 프로젝트 구조

```plaintext
src/
├── App.java         // 프로그램 실행 및 흐름 제어
├── Calculator.java  // 연산 처리 및 결과 저장
├── Input.java       // 사용자 입력 수집 및 유효성 처리
├── Valid.java       // 입력값 유효성 검사
└── UI.java          // 사용자 인터페이스 및 메뉴 제어
```

---

## 📜 클래스 설명

### App.java
- **역할:** 프로그램 전체 흐름을 제어하는 메인 클래스
- **주요 기능:**
  - 사용자로부터 두 정수와 연산자를 입력받음
  - `Calculator 클래스`를 통해 연산 처리
  - `UI 클래스`를 통해 결과 출력 및 메뉴 제공
  - `"exit"` 입력 전까지 반복 수행

### Calculator.java
- **역할:** 연산을 처리하고 결과를 저장
- **주요 기능:**
  - `calc(int v1, int v2, char op)`: 사칙연산 수행
  - `saveOutput(double result)`: 결과 포맷 조정 후 저장
  - `getResult()`: 마지막 연산 결과 반환
  - `getResults()`: 모든 결과 리스트 반환
  - `removeResult()`: 첫 번째 결과 삭제
  - `피연산자, 연산자 getter & setter`: 피연산자, 연산자 반환 & 수정

### Input.java
- **역할:** 입력 및 유효성 검사 요청
- **주요 기능:**
  - `inputOperand()`: 피연산자 입력 및 정수 유효성 검사
  - `inputOperator()`: 연산자 입력 및 단일 연산자 유효성 검사
  - `inputMenu()`: 메뉴 입력

### Valid.java
- **역할:** 유효성 검사
- **주요 기능:**
  - `isItOperator(String)`: 연산자 유효성 검사 및 char 변환
  - `isItPositive(String)`: 0 포함 양의 정수 유효성 검사 및 int 변환

### UI.java
- **역할:** 메뉴 UI 출력 및 처리
- **주요 기능:**
  - `menuUI()`: 메뉴 출력 및  처리
    - 추가 계산
    - 결과물 전체 보기
    - 첫 번째 결과 삭제
    - 프로그램 종료를 위한 키워드 제공 (`"exit"`)

## 📋 기능 예시

```
===========계산기===========
첫번째 정수를 입력하여주십시오: 5
두번째 정수를 입력하여주십시오: 3
수식을 입력하여주십시오: +

연산 결과: 5 + 3 = 8

===========메뉴창===========
메뉴를 선택해 주십시오. 
1. 더 계산하시겠습니까?
2. 결과물들을 출력하시겠습니까? (2 입력)
3. 제일 첫 결과물을 삭제하시겠습니까? (3 입력)
4. 종료하시겠습니까? (exit 입력)

exit
(종료)
```

## ✅ 특이사항 및 예외 처리

- 0으로 나누기를 시도할 경우 에러 방지
- null값을 반환하려는 경우 NullPointException 방지
- 너무 작은 소수는 지수 형태로 출력
- 3자리수 이상인 결과 값은 반올림하여 출력
- 피연산자는 **최대 9자리** 정수까지 허용 (10자리 초과 시 에러)
